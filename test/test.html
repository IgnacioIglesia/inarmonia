Validación con señales sintéticas

Generamos notas con f0 y B conocidos (con ruido, zumbido de 50 Hz y ataque ruidoso), pasamos cada una por el pipeline completo y comparamos lo medido con lo verdadero.

Criterios de aceptación

  • Error de f0 menor a 0.05 Hz.
  • Error relativo de B menor a 5 %.
  • Frecuencias de armónicos: error máximo reportado (sin umbral fijo: se muestra para discutir).
